# Instruction screen images

Place five PNG (or JPG) images in this folder:

| File | Content |
|------|---------|
| `step-1.png` | Move left — raise left arm |
| `step-2.png` | Move right — raise right arm |
| `step-3.png` | Fly — both arms up |
| `step-4.png` | Duck / squat — T-pose or squat |
| `step-5.png` | Ready to play / calibration |

Paths are referenced from `index.html` as `instructions/step-N.png`.
